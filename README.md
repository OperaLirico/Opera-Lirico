# 意大利声乐现场

一个可添加到手机主屏幕的意大利声乐信息网页。它每天用 Scrapling 查看 29 个剧院/比赛来源和 14 个音乐学院入学考试页面：前者给页面状态与招募摘录，后者给报名期限、考试日期、入学要求与官方 PDF 链接。页面内另有歌名搜索：收录作品可先查看公版歌词原文和中文大意，再打开 IMSLP 查看乐谱版本及下载选项。顶部的“正在报名”只列出经过人工确认的项目；网页摘录不代表项目仍在招募。

## 每天自动更新

GitHub Actions 每天 06:15 UTC 开始抓取并发布网页。意大利冬令时为 07:15，夏令时为 08:15。也可以在 GitHub Actions 页面手动运行。自动任务在 GitHub 上执行，不需要个人电脑开机。

## 手机使用

- iPhone：用 Safari 打开网页，点“分享”图标，再点“添加到主屏幕”。
- Android：用 Chrome 打开网页，选择“安装应用”或“添加到主屏幕”。

安装后会以独立窗口打开，并缓存页面外观；联网时会读取最近一次抓取的数据。

## 数据说明

- 每天检查各机构和专业信息平台当前公开的网页，不绕过登录、验证码或付费限制。
- 乐谱由 IMSLP 按作品页提供；本站不托管 PDF。不同版次及国家/地区的版权状态可能不同，下载前请查看来源页标注。
- 歌词文本来自 LiederNet Archive 与意大利语 Wikisource 的公开页面，按日增量收录；未收录的歌曲会提供外部搜索入口。
- 音乐学院部分只摘录各校官网公开的招生页面：报名期限与考试日期保留原文表述，完整的分专业曲目要求通常在校方 PDF 里，卡片会直接给出官方文件链接。
- 网页结构变化、PDF 或第三方报名表可能无法自动读取；每条来源都保留官网链接供核对。
- 自动摘录用于查找线索，不代表已确认仍可报名，也不保证覆盖所有机会。
- 报名资格、截止时间和费用请以主办方原始公告为准。

## 歌词与乐谱搜索

首页提供一个合并搜索：输入咏叹调或艺术歌曲名称，先查看收录的公版原文，再打开 IMSLP 作品页查看乐谱版本。本站不存储或分发乐谱文件；具体版本和各地区版权状态请以来源页面为准。搜索支持关键词、前缀与少量拼写容错：只输入 `nessun` 这样的词根就会列出相关曲目，并给“继续检索”的建议入口；歌词默认折叠，名单最多显示 12 条，命中正文时会把那一句原文摘出来。

## 每日扩充曲目库

每日工作流从 LiederNet Archive 的原语页目录整理新文本，并写入站内目录；页面搜索和显示使用本地生成的数据，不要求访客打开 LiederNet。文本 id 取自站点 sitemap，用固定种子打散后按位置游标逐日取用，每天扫描 48 个页面、最多写入 12 条，因此既不会重复，也不会连着几天只出一门语言。入库范围只有独唱声乐作品：带乐队编制的段落标为“咏叹调/歌剧选段”，其余标为“艺术歌曲”，合唱与康塔塔类条目跳过；译文页也跳过，避免同一首诗反复入库。歌剧唱段另由 `update_arias.py` 从意大利语 Wikisource 的《Libretti d'opera》按幕/场拆条，标题形如“歌剧 · Atto I · Scena V”，搜索唱段首句即可命中。每次自动导入都保留作品名和来源归属。未经核验版权/版次的乐谱不会从 IMSLP 镜像；仅当目录中有 `downloadUrl` 指向本站已核验文件时才显示站内下载按钮。

静态网页无法在每位用户输入陌生歌名时即时触发服务器抓取；未收录的作品会提示曲目库每日更新，之后可在站内重新搜索。IMSLP 的下载等待仅适用于其自身下载流程；本站不会伪造倒计时或绕过该限制。
