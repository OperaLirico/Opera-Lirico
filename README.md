# 意大利声乐现场

一个可添加到手机主屏幕的意大利声乐信息网页。它每天用 Scrapling 查看 15 个公开来源，展示页面状态、公告相关摘录和主办方链接。顶部的“正在报名”只列出经过人工确认的项目；网页摘录不代表项目仍在招募。

## 每天自动更新

GitHub Actions 每天 06:15 UTC 开始抓取并发布网页。意大利冬令时为 07:15，夏令时为 08:15。也可以在 GitHub Actions 页面手动运行。自动任务在 GitHub 上执行，不需要个人电脑开机。

## 手机使用

- iPhone：用 Safari 打开网页，点“分享”图标，再点“添加到主屏幕”。
- Android：用 Chrome 打开网页，选择“安装应用”或“添加到主屏幕”。

安装后会以独立窗口打开，并缓存页面外观；联网时会读取最近一次抓取的数据。

## 数据说明

- 每天检查各机构当前公开的网页，不绕过登录、验证码或付费限制。
- 网页结构变化、PDF 或第三方报名表可能无法自动读取；每条来源都保留官网链接供核对。
- 自动摘录用于查找线索，不代表已确认仍可报名，也不保证覆盖所有机会。
- 报名资格、截止时间和费用请以主办方原始公告为准。
