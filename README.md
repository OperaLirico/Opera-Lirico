# 意大利声乐现场

一个可添加到手机主屏幕的意大利声乐信息网页。它每天用 Scrapling 查看一批剧院/比赛来源（目前 40+ 个，每天自动从已收页面里再发现新的招募页）和 52 所音乐学院入学考试页面（覆盖 AFAM 名单的大部分，且每天自动从维基数据的官方站点记录里继续追加）：前者给页面状态与招募摘录，后者给报名期限、考试日期、入学要求、页面要点与官方 PDF 链接。页面内另有歌名搜索：收录作品可先查看公版歌词原文和中文大意，再打开 IMSLP 查看乐谱版本及下载选项。顶部的“正在报名”只列出经过人工确认的项目；网页摘录不代表项目仍在招募。
剧院/比赛来源不是写死的清单：每天抓取时会把页面里指向别家 audizioni/bando 的站外链接挑出来，先实抓验证（能不能打开、是否确实在招人），再把通过的收进 `data/sources_extra.json`（跟着仓库一起提交），每轮最多新增 8 条、复检 12 条；分享按钮、报名表、招聘乘务/后台人员和舞蹈/征文比赛会被排除。长期打不开的条目累计 4 次失败后自动移除。

## 目录

- `index.html`、`app.js`、`styles.css`、`extra.css` — 静态站点，直接放进浏览器就能用；`service-worker.js` 缓存外壳文件，数据文件走网络优先。
- `scrape_sources.py` — 手选的剧院/比赛来源，抓正文里的招募要点。
- `grow_sources.py` — 从已收页面再发现新的招募来源，并轮转复检。
- `run_conservatori.py` / `scrape_conservatori.py` — 音乐学院入学考试采集（重试、超时后可沿用上次成功快照）。
- `grow_conservatori.py` — 从维基数据里找还没收的国立音乐学院官网，验证招生页可读后写入 `data/conservatori_extra.json`，次日进入抓取清单。
- `update_repertoire.py`、`update_arias.py`、`prune_repertoire.py` — 曲目库每日扩充与清理。
- `data/*.json` — 抓取结果与曲目库，由每日工作流生成。

## 几点说明

- 学院页面抓不到属于常见情况：都灵、热那亚两台服务器对自动化访问经常直接超时，卡片会显示“本次未连通，显示上一次成功读取的内容”。
- 来源清单会自己长大，但不会无限膨胀：新条目必须是能打开且确实在招人的页面；过期通知页会在连续四次失败后自动退出。
- 乐谱由 IMSLP 按作品页提供；本站不托管 PDF。不同版次及国家/地区的版权状态可能不同，下载前请查看来源页标注。
- 音乐学院清单不是写死的：每轮从维基数据补齐尚未收录的院校（每轮最多 6 所，先验证招生页确实能读出内容才收录）；只摘录各校官网公开的招生页面：报名期限与考试日期保留原文表述，完整的分专业曲目要求通常在校方 PDF 里，卡片会直接给出官方文件链接。
- 网页结构变化、PDF 或第三方报名表可能无法自动读取；每条来源都保留官网链接供核对。
