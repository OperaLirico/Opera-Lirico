# 个性化声乐机会匹配（第一阶段）

`content_engine/matcher.py` 是一个纯匹配模块：输入声部、具体年龄和感兴趣的机会类型，输出符合条件的已核实机会。

## 当前规则

- 仅匹配官方发布、已核验、状态为 published 的机会。
- 排除已截止或没有可解析截止日期的机会。
- 按声部匹配；若官方声部字段为 unspecified，则作为“需要向主办方确认”的候选，不声称一定符合。
- 如果公告提供年龄上下限，超出范围的机会会被排除；未提供年龄范围的机会会明确标注“需查看章程确认”。
- 兴趣类型支持比赛、歌剧院/合唱团招募、青年艺术家项目和大师班。
- 输出包含官方链接和匹配原因，方便用户自行复核。

## 本地试运行

准备一个本地 JSON 文件（不要提交真实个人资料），例如：

```json
{
  "voice_type": "tenor",
  "age": 30,
  "interests": ["competitions", "opera_house_auditions"]
}
```

运行：

```bash
python -m content_engine.matcher profile.example.json
```

测试：

```bash
python -m unittest tests.test_matcher -v
```

## 隐私边界

本阶段不保存个人资料、不读取订阅者邮箱、不发送邮件。正式接收姓名、邮箱、声部和年龄之前，还需要确定数据控制者/隐私政策、明确同意文本、保留期限、用户访问/更正/删除流程，以及安全存储和邮件确认机制。匹配引擎先独立完成并测试，再接入用户登记表。
