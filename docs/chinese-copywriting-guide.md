# 中文文案规范｜Italia Audizioni

## 品牌语气

Italia Audizioni 面向在意大利学习、训练或发展的古典声乐学生与年轻歌手。中文表达应当专业、准确、自然、克制；像一位熟悉意大利音乐院校与歌剧行业的人在提供实用信息。

- 专业但不官腔：不用行政公文式表达。
- 自然但不随意：避免网络口语、俏皮话和开发者自言自语。
- 具体而诚实：说明信息是什么、适用于谁、下一步能做什么。
- 不夸大：网页抓取成功不等于机会仍开放；页面有链接不等于招生信息已核实。
- 保留必要的意大利语专有名词，首次出现时可配中文解释。

## 避免的表达

| 避免 | 推荐 |
|---|---|
| 所读到 | 所院校 / 所院校资料已收录 |
| 歌词默认折着 | 点击后可展开完整歌词 |
| 不用满网找下载按钮 | 集中查看官方招生文件 |
| 去主办方页面看 | 查看主办方公告 |
| 这次没读到官网 | 本次未能读取官网 |
| 现在没有确认在招的项目 | 暂无已确认仍在报名的项目 |
| 点两个字搜歌 | 按作品名、作曲家或歌词搜索 |
| 先查这四件事 | 查看机会、招生信息与曲目资料 |

## 术语统一

- Audizione：试唱 / 选拔（依语境选择）
- Concorso：比赛 / 竞赛
- Bando：招生简章 / 招募公告（依语境选择）
- Conservatorio：音乐学院
- Accademia：学院；明确为歌剧院培训项目时称“歌剧院学院”
- Candidatura：申请 / 报名
- Scadenza：截止日期
- Requisiti：申请条件 / 报考要求
- Programma：考试曲目 / 考试内容 / 课程安排（依语境选择）
- Canto lirico：歌剧演唱 / 古典声乐（依语境选择）

## 信息状态用语

- 报名开放：官方资料支持当前仍可报名，且已核对日期。
- 已截止：官方资料明确显示报名期限已过。
- 尚未公布：已查看官方页面，但没有找到本学年招生日期。
- 待核实：已有相关线索，但不足以确认状态。
- 暂无法读取：本次自动访问失败，不代表该机构没有招生信息。
- 资料已收录：只说明页面或文件已被系统读取，不代表内容已核实。

## 文案原则

1. 日期使用“2026 年 11 月 10 日”格式；如涉及时间，明确标注意大利当地时间。
2. 不把网页抓取状态写成招生状态。
3. 不把往年文件描述为本学年招生信息。
4. 不把原文机器翻译直接作为确定事实；不确定时保留意大利语原文并标注待核实。
5. 句子优先采用“信息 + 用户价值”的结构，避免口号、夸张承诺和无意义的填充语。
