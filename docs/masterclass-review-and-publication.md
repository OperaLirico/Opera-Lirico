# 大师班审核与发布流程

## 自动发现

`discover_masterclasses.py` 每日读取 `data/masterclass_sources.json` 中的来源，并将符合关键词、声乐相关性和未来日期信号的线索写入 `data/masterclass_candidates.json`。发现结果只是线索，不等于报名仍开放，也不等于已经核实。

## 人工核验

在私有运营后台的“大师班候选审核”中逐条处理：

1. 打开候选页面，找到主办方自己的课程公告、官方日历、Bando 或报名文件。
2. 核对课程名称、教师、适用声部/对象、地点、课程日期、报名截止、费用、申请方式。
3. 在审核表中填写主办方官方 HTTPS 链接，并粘贴至少 40 个字符、直接支持关键信息的官方原文。
4. 官方证据链接必须属于候选所标记的主办方域名或其子域名；第三方目录不能通过核验门槛。
5. 日期或费用冲突、关键字段缺失时，选择“需要补充信息”，并记录问题；已过期且没有延期证据时选择“排除”。

审核记录保存在私有 KV 中，包含审核状态、备注、官方证据链接、原文摘录和审核时间。

## 发布边界

“核实通过（待发布）”只表示审核通过，不会直接写入公开的 `data/masterclasses.json`。正式发布仍需编辑完整中文展示字段、确认所有关键字段和证据，再通过公开数据校验。公开数据必须同时满足：

- `publisher_status=official`
- `review_status=verified`
- `publication_status=published`
- 至少一条可追溯的官方证据记录

不允许从第三方目录、搜索摘要或自动日期提取结果直接发布。

## 自动化边界

自动化负责发现、去重、保留审核状态和提示风险；它不能把 HTTP 200、关键词命中或第三方页面当成事实核验。任何不能由官方来源支持的字段都保持未确认。
