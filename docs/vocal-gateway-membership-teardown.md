# VocalGateway 会员与订阅板块拆解（REA 第 6 轮）

研究日期：2026-11-18　对象：`/zh/membership`、`/zh/terms`、`/zh/opportunities`（会员墙实际呈现）
方法：只读公开页面与条款文本；不登录、不购买、不抓取会员内容。

---

## 1. 产品架构：两档、单一 SKU、一堆线下服务

| 档 | 权益 | 价格 |
|---|---|---|
| 免费 | 50 条精选机会（古典声乐 25 / 音乐剧 15 / 合唱 10）、免费艺术主页（1 款模板、自定义网址、图片/影音/曲目展示） | ¥0 |
| 年度会员 | 100+ 精选机会**完整查看**、个性化推荐、**每自然月 3 份深度研究与预算报告**、历史报告保存及 PDF 下载、3 款模板 | ¥99 / 年，支付确认起 365 天，**不自动续费** |

页面自己写明了一句关键的商业边界：「**网站在线支付只用于 ¥99 年度会员。**」

视频点评、一对一课程、协助申请 **不走网站订单**，走预约二维码、线下另行安排与支付（条款第 6 条）。→ 支付面只留一个 SKU，退款、对账、渠道复杂度被压到最低。

> 口径说明：定价页与条款都写「100+ 精选机会」。我在第 3 轮记录过「495 条」，那更像库总量或旧版统计；未登录无法核实会员可见数，本文件按官方公开口径为准。

## 2. 额度引擎：五条把争议提前消灭的规则

这一段是整站最值得抄的「结构」，不是文案：

1. **重置口径**：每自然月 3 份，**按上海时区自然月重置，不累计到下月**。
2. **计入条件**：**只有成功完成的新报告计入额度**。
3. **明确不扣的情形**：失败、未完成、查看历史报告、下载已有 PDF、复用已有报告——**一律不重复扣减**。
4. **历史不可被改写**：研究快照后续更新**不自动改写**用户已生成的历史报告。
5. **额度与产物分离**：报告存账户里，重开与下载不消耗额度。

这五条把「我这次算不算用了额度」「我上个月剩的能不能攒」这两个必然出现的客服问题，在条款层面答完了。

## 3. 降级行为：到期不毁数据

条款第 5 条写得很清楚：会员到期后，用户**仍保留**账户、历史报告、历史 PDF、已发布的免费主页内容；只**失去**会员专属机会、新报告、模板切换等权益，直到续费。

→ 降级的边界是「新产出停、旧产出留」。这对订阅信任的作用比任何折扣都大。

## 4. 会员墙的形状（列表页实测）

列表页上锁定卡片出现 126 次（每卡一个锁图标），文案两种：

- 免费卡：「会员机会 / **基础信息可见，完整详情、官方申请入口与资格核对需要会员。**」+「查看会员权益」
- 锁定卡：标注「会员机会预览」，只露基础字段。

**他们连「官方申请入口」也锁在墙后。** 这是他们商业模式的核心——卖的是「核对 + 入口」，不是「信息」。

我们的判断：这个具体选择不借。锁官方入口对用户是敌意设计，也容易被主办方视为截流。我们的等价物应该是「**准备与研究**」在墙后，官方链接永远公开。

## 5. 条款里值得单独记的三段

1. **未知字段的三种处理，写进合同**：信息缺失时「标记为『官方未公布』『待确认』**或隐藏该字段**」，并补一句「**未知信息不等于零费用、无要求或自动符合**」。后半句是法律与认知的双重防线。
2. **AI 的合规预热**：条款写明报告「基于生成时可获取的公开资料、Research Snapshot、用户条件与预算输入生成」；竞争强度、复杂度、预算区间「属于研究性估计，不是录取概率、艺术水平评价、法律意见、签证承诺或实时报价」。同时在第 12 条免责里把「AI 服务」列为不可保证无错的第三方之一。
3. **反抓取靠条款而非技术**：robots 是 `Allow: /` + 声明 sitemap，公开 payload 带 50 条机会与证据；条款第 9、10 条禁止「批量抓取或复制数据库」「系统性复制、出售、再分发」。→ 他们选择「开放发现 + 法律声明」，而不是技术封锁。

## 6. 软权益：两个不给数字的差异化

会员权益里混了两条非量化项：**协助申请优先排期**、**符合条件的专家服务会员优惠**。它们既提高了会员感知价值，又不增加边际成本，也不承诺结果。

## 7. 可借 / 不借

**借**

1. 额度五条规则（重置口径、计入条件、不扣情形、历史不可改写、额度与产物分离）——照结构，不照文案。
2. 降级只停新增、不清历史。
3. 单一 SKU 在线支付，专业服务走线下，不混进订单系统。
4. 365 天不自动续费：降低退款与投诉面。
5. 「未知 ≠ 零」这句话变成条款句式。
6. AI 产出的免责与输入披露，写在服务条款而不是藏在角落。
7. 锁卡片的呈现方式：基础字段可见 + 一句实话说明锁什么（语气平实，不制造焦虑）。
8. 两条软权益（优先排期、会员优惠）。

**不借**

1. 锁官方申请入口。
2. ¥99 这个价格锚点（我们的人力成本结构不同，定价要按准备包的成本反推）。
3. 「100+ 机会」这种靠规模说话的价值主张——我们没有也不该有第二个机会库。
4. 用「研究快照」当不更新历史报告的理由可以借，但不能把它变成「永远不修正错误」的挡箭牌。

## 8. 落到 OperaLab 的会员模型（建议）

**两档：**

- **免费**：47 条结构层、13 个热区、机制页、术语检索、小测、掌握进度（本地）。= 我们现在的全部公开层。
- **会员**：每月 **2 份「大师班准备包」**（8 章深入：人声条件 / 曲目与语言 / 费用与差旅 / 签证与时间线 / 风险 / 下一步 / 来源 / 核对日期）+ 历史包永久可读 + 语音示范扩展包。

**额度规则照抄结构，不抄文案：**

1. 按欧洲中部时间自然月重置，不累计。
2. 只有成功生成的准备包计额度。
3. 失败、未完成、重开历史、下载 PDF 不扣。
4. 事实更新会**新增修订版**并标注，不改写已生成的历史包（这一条比他们更严：我们允许修正，但以版本形式）。
5. 额度与产物分离：包在账户里，随时重开。

**降级**：到期保留历史包与账户，失去新包与语音扩展。

**支付**：只在线卖一个年费 SKU；一对一课程、签证与行程咨询走线下。

**价格**：不定 ¥99。按「一份准备包 ≈ 若干小时研究 + 核对」反推，先做 10 份内部试用包测工时，再定价。

**关键差异（对外一句话）**：他们锁入口，我们不锁；他们给机会清单，我们给「这场大师班你会遇到什么、要准备什么」。
